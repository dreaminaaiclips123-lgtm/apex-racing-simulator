# Adding photos to the website gallery

The "Inside the garage" section on the homepage shows whatever photos are in this folder — no code changes needed.

## How to add a photo

1. Go to this folder on github.com (ask whoever set up the site for the link, or find it in your repo under `public/gallery/`).
2. Click **Add file → Upload files**.
3. Drag in your photo (`.jpg`, `.png`, `.webp`, or `.avif`).
4. Commit the change (write anything in the commit message box, then click **Commit changes**).
5. Wait about a minute — the live site rebuilds automatically and your photo appears.

## Tips

- Name files starting with numbers to control the order they appear in, e.g. `01-bay-3.jpg`, `02-drift-night.jpg`.
- Landscape photos (wider than tall) look best, but any size works.
- If there are no photos in this folder, the gallery section is simply hidden — the site never shows a broken/empty gallery.
- To remove a photo, delete the file the same way (click it on github.com → trash icon → commit).
